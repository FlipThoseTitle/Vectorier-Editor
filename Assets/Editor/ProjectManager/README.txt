Installation:

For Unity Version:
1. Copy the folder called "Vector_Data"
2. Paste it into your game directory, replace existing file if asked.

For Steam Version:
1. Copy all of the files inside "Vector" Folder
2. Paste it into your game directory, replace existing file if asked.
